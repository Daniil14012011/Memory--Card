# Memory--Card
Проект "Memo Card" — это простая программа для викторин на Python (PyQt5).

Что делает:
Показывает вопросы с четырьмя вариантами ответов. Правильный ответ при каждом запуске случайно перемешивается с неправильными. После выбора варианта программа сообщает, верен ли он, показывает правильный ответ и выводит в консоль статистику (количество вопросов, правильных ответов и процент успеха).

Как работает:
Интерфейс переключается между двумя панелями: одна для выбора ответа, другая — для показа результата. Кнопка "Ответить" после нажатия превращается в "Следующий вопрос".

Особенности кода:

Данные о вопросах хранятся в классе Question.
Для перемешивания ответов используется список ссылок на кнопки и функция shuffle.
Статистика (счетчики score и total) привязана напрямую к объекту окна (window).

Как добавить вопросы:
Создать новый объект Question('Текст', 'Правильный', 'Неправ1', 'Неправ2', 'Неправ3') и добавить его в список questions_list.
